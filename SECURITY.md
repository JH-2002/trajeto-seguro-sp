# Política de segurança

## Reportando uma vulnerabilidade

Se você encontrar uma falha de segurança (por exemplo, execução de código a partir de um link compartilhado, injeção de conteúdo no inspetor ou exposição de dados pessoais), **não abra uma issue pública**.

Use o recurso **Report a vulnerability** na aba **Security** do repositório (GitHub Private Vulnerability Reporting). O relato fica visível apenas para o mantenedor.

Inclua, se possível:

- descrição do problema e do impacto;
- passos para reproduzir (ou um link de rota que demonstre o problema);
- navegador e sistema utilizados.

Você receberá uma resposta assim que possível. Correções são publicadas na branch `main` e o site é republicado automaticamente.

## Escopo

- Código deste repositório (front-end e scripts de dados).
- O site publicado em https://jh-2002.github.io/trajeto-seguro-sp/.

Serviços de terceiros (OpenFreeMap, OSRM/FOSSGIS, Photon, portais da SSP-SP e GeoSampa) estão fora do escopo: reporte diretamente aos responsáveis.
